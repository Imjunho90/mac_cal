Mini NPU Simulator

1. 실행 방법

프로그램은 Python 3.8 이상의 환경에서 실행할 수 있으며 외부 라이브러리는 사용하지 않는다.

python main.py

실행하면 다음 두 가지 모드 중 하나를 선택할 수 있다.

* 1. 사용자 입력 (3x3) : 사용자가 3×3 필터 A, B와 패턴을 직접 입력하여 MAC 연산 결과를 확인한다.
* 2. data.json 분석 : data.json에 저장된 5×5, 13×13, 25×25 필터와 패턴을 불러와 일괄 분석한다.

data.json 파일은 main.py와 같은 경로에 위치시킨다.

⸻

2. 구현 요약

라벨 정규화

JSON 데이터에서 동일한 의미를 가진 라벨이 서로 다른 형태로 표현될 수 있기 때문에 프로그램 내부에서는 Cross와 X 두 가지 표준 라벨을 사용한다.

* + → Cross
* cross → Cross
* x → X

normalize_label() 함수를 이용하여 필터의 키와 각 패턴의 expected 값을 동일한 표준 라벨로 변환한 뒤 판정 결과와 비교한다.

MAC 연산

MAC(Multiply-Accumulate) 연산은 입력 패턴과 필터에서 동일한 위치에 있는 값을 서로 곱하고 그 결과를 모두 누적하여 하나의 점수를 계산하는 방식이다.

본 프로그램에서는 NumPy 등의 외부 라이브러리를 사용하지 않고 이중 반복문을 이용하여 직접 MAC 연산을 구현하였다.

for i in range(len(pattern)):
    for j in range(len(pattern[i])):
        score += pattern[i][j] * filters[i][j]

Cross 필터와 X 필터에 대해 각각 MAC 점수를 계산한 후 더 높은 점수를 가진 필터를 최종 결과로 판정한다.

동점 처리 정책

Python의 부동소수점 연산에서는 계산 과정에서 매우 작은 오차가 발생할 수 있기 때문에 두 점수를 단순히 ==로 비교하는 것은 적절하지 않을 수 있다.

따라서 본 프로그램에서는 epsilon 값을 다음과 같이 설정하였다.

eps = 1e-9

두 점수의 차이에 대해 다음 조건을 만족하면 실질적으로 동일한 값으로 판단한다.

abs(score_a - score_b) < eps

조건을 만족하는 경우 결과를 UNDECIDED로 처리한다.

FAIL 케이스 원인 분석

data.json 분석 결과 총 6개의 테스트 케이스 중 3개가 PASS, 3개가 FAIL로 판정되었다.
실패한 케이스는 size_5_1, size_13_2, size_25_1이며 세 케이스 모두 두 필터의 점수 차이가 epsilon보다 작아 UNDECIDED로 판정되었다.
size_5_1은 Cross 점수가 0.9, X 점수가 0.8999999999999999로 계산되었다. 두 값은 표현상 차이가 있지만 그 차이가 epsilon보다 작기 때문에 동점으로 처리하였다.
size_13_2는 Cross 점수가 7.499999999999997, X 점수가 7.5로 계산되었으며 마찬가지로 epsilon 범위 내에 있어 UNDECIDED로 처리하였다.
size_25_1 역시 Cross 점수가 4.9, X 점수가 4.899999999999999로 계산되어 epsilon 기준에 따라 동점으로 처리하였다.
이러한 미세한 차이는 컴퓨터가 일부 실수를 이진 부동소수점으로 정확하게 표현하지 못하면서 발생할 수 있다.
따라서 단순한 대소 비교만 사용하면 실제로는 동일하게 취급해야 할 값이 Cross 또는 X로 잘못 판정될 가능성이 있다.
본 프로그램에서는 abs(score_a - score_b) < 1e-9 조건을 적용하여 이러한 경우를 UNDECIDED로 판정하였다.
세 케이스의 expected 값은 각각 X, Cross, X였지만 실제 판정 결과가 UNDECIDED였기 때문에 최종적으로 FAIL 처리되었다.
반면 나머지 3개의 테스트 케이스는 두 필터의 점수 차이가 명확했고 판정 결과와 expected 값이 일치하여 PASS 처리되었다.

성능 분석

실행 환경에서 10회 MAC 연산의 평균 시간을 측정한 결과는 다음과 같다.

크기	평균 시간(ms)	연산 횟수(N²)
3×3	0.002	9
5×5	0.003	25
13×13	0.015	169
25×25	0.053	625

MAC 연산에서는 N×N 패턴의 모든 위치를 한 번씩 순회하여 패턴과 필터의 값을 곱하고 결과를 누적한다.
따라서 N×N 크기의 데이터에서는 총 N²개의 원소에 대한 연산이 필요하다.
실제로 크기가 증가하면서 연산 횟수는 9회 → 25회 → 169회 → 625회로 증가하였다.
측정된 평균 연산 시간 역시 0.002ms → 0.003ms → 0.015ms → 0.053ms로 전반적으로 증가하였다.
따라서 본 프로그램에서 구현한 MAC 연산의 시간 복잡도는 **O(N²)**라고 볼 수 있다.
단, 실제 측정 시간은 Python 인터프리터, 운영체제의 프로세스 스케줄링 및 실행 환경 등의 영향을 받을 수 있기 때문에 연산 횟수 N²에 정확하게 비례하지는 않을 수 있다.
